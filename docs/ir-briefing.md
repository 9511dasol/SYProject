## 총괄 (한 문단 요약)

**2026년 11월, 2주간 7건의 고도화를 완료해 제품을 "수치 조회 도구"에서 "다음 행동을 알려주고, 그 행동(소재 제작)까지 한 곳에서 처리하는 도구"로 격상시켰다.**
리포트 분석 2건(기간 비교, 액션 제안) → 크리에이티브 3건(요소 편집, 배경 시안, 규격 일괄 변환) → 플랫폼 안정성 1건(동시성·데이터 보존), 그리고 경쟁사 벤치마크 리서치 1건. 전 과정에서 백엔드 자동 테스트를 322건 → 342건으로 늘려 회귀 없이 검증했다.

**IR 핵심 스토리 한 줄**: 경쟁사(이미지팩토리)는 "소재 제작 → 집행 → 성과"로 흐르지만, 우리는 **"실데이터 성과 분석 → 액션 제안 → 소재 제작"의 역방향 루프**다. 리포트가 "소재를 점검하라"고 말하면, 같은 화면에서 바로 소재를 고칠 수 있다.

## 경쟁 구도와 우리의 위치

국내에서 우리 기능과 겹치는 대표 플레이어 3곳 — 각자 한 조각씩에 특화돼 있고, **세 조각(분석→액션→소재)을 한 제품에 담은 곳은 없다.**

| 경쟁사 | 무엇에 특화 | 과금 구조 | 우리와의 관계 |
|---|---|---|---|
| **[이미지팩토리](https://www.imagefactory.co.kr/)** (엠제이스튜디오) | AI 광고 소재 제작·리사이즈·다채널 집행 | 소재 제작 포인트 종량제(배너 1장 ≈ $1) + 구독($20~95/월) | 크리에이티브(④⑤⑥) 영역이 겹침 — 단, 성과 "분석"은 집행 후 관리 수준 |
| **[에이비딩](http://a-bidding.com/)** (DMP코리아) | 네이버·카카오 SA **자동입찰**(24시간 순위 유지), 자매 제품 '피라미드'(리포트 자동화) | 솔루션 구독 | 입찰 "실행"에 특화 — 우리의 액션 제안(②)이 "입찰가를 확인하라"까지 알려주면, 실행 단계에서 이런 툴과 접점. 리포트 자동화(피라미드)는 ①과 겹침 |
| **[아드리엘](https://www.adriel.com/)** | 650+ 채널 **통합 대시보드**, AI 인사이트, KPI 알림, 화이트라벨 PDF | 데이터 소스 수 기반 구독(월 수십만 원대~) | 리포트·대시보드(①②) 영역이 겹침 — 단, 소재 제작 기능 없음 |

**우리의 포지션**: 셋 중 어느 하나의 규모를 흉내 내는 게 아니라, **사내 실무 워크플로우(엑셀 리포트 양식)를 그대로 수용하면서 분석→액션→소재 제작을 한 화면에 잇는 것.** 범용 SaaS가 못 하는 두 가지 — ①기존 엑셀 리포트 파일을 그대로 읽고 쓰는 호환성(별도 API 연동·셋업 없이 당일 시작), ②고정 구독료 없는 원가 구조(룰 엔진·이미지 처리는 비용 0, AI는 원가 종량) — 가 소규모 팀·대행사에겐 도입 장벽 차이로 직결된다.

## 영역 1 — 리포트 분석: 숫자를 보여주는 것에서 "행동을 알려주는 것"으로

### ① YoY/MoM 기간 비교 리포트

**결론: 월간 리뷰가 "작년 10월 vs 지난달 vs 이번 달"을 한 화면에서 비교해 준다 — 달을 오가며 수기로 비교하던 작업이 사라졌다.**

| 구분 | 내용 |
|---|---|
| **언제** | 2026-11-10 완료 |
| **어디서** | SA 광고 대시보드 → 월간 리뷰 요약 탭 |
| **무엇을** | 전년동월(YoY)·전월(MoM) 비교를 두 가지 뷰로 제공 — ①KPI 카드 10종마다 `전월 +16.3% · 전년 -24.2%` 증감 칩, ②3개 기간을 지표별로 나란히 놓은 기간 비교 표 |
| **어떻게** | 리포트 API가 당월 실적과 비교 기간 합계를 함께 반환. CTR·CPC·ROAS 파생지표는 당월과 동일 공식으로 계산해 증감률 왜곡 방지. 비교 달 데이터가 없으면 숨겨 "-100%" 같은 거짓 증감 차단 |
| **왜** | 광고는 계절성이 강해(10월 성수기 등) 전월 비교만으로는 성과 판단이 왜곡된다. DB에 쌓인 과거 데이터(2025-01~)를 활용할 방법도 없었다 |
| **성과·검증** | 회귀 테스트 3건 추가, 실데이터 화면 검증 완료 |
| **경쟁 비교** | 기간 비교 자체는 아드리엘 등 통합 대시보드도 제공하고, 네이버 광고관리시스템에도 기간 선택이 있다. **우리가 나은 점**: ①실무에서 쓰던 **엑셀 리포트 양식('전월'·'전년동월' 행)과 지표 정의가 1:1로 일치** — 대시보드 숫자와 보고서 숫자가 어긋나는 범용 툴의 고질적 문제가 없다. ②API 연동·셋업 없이 **쓰던 엑셀을 업로드하는 것만으로 과거 35개월치 비교가 즉시 가동** — 실제로 양식이 전혀 다른 대행사 주간 리포트(25MB `.xlsb`)를 업로드 기능으로 적재해 19개월 → 35개월로 늘린 사례가 있습니다(2026-11-24). ③구독료 0 (아드리엘은 데이터 소스 기반 월 구독) |

### ② CTR/ROAS 지표 기반 액션 제안

**결론: 대시보드가 "CTR이 떨어졌다"에서 끝나지 않고 "소재를 점검·교체하라"까지 말해 준다 — 주니어 담당자도 데이터 기반 대응이 가능해졌다.**

| 구분 | 내용 |
|---|---|
| **언제** | 2026-11-10 완료 |
| **어디서** | 월간 리뷰 요약 탭 "액션 제안" 섹션 |
| **무엇을** | 지표 상태를 읽어 권장 액션을 카드로 제시 — ROAS 100% 미만→입찰가 하향, CTR 하락→소재 점검·교체, CPC 급등→입찰 경쟁 점검, 전환율 하락→랜딩 점검, 매체별 진단, 긍정 신호(예산 확대 제안)까지 7종 룰 |
| **어떻게** | AI 호출 없는 **결정적 룰 엔진** — 토큰 비용 0, 리포트를 열 때마다 즉시 계산. 모든 제안에 근거 수치 병기(예: "구글 ROAS 83.3% (계정 전체 159.7%)")해 타당성을 바로 검증 가능. ①의 기간 비교 데이터를 재사용 |
| **왜** | 수치는 보여줘도 "그래서 뭘 해야 하는지"는 담당자 경험에 의존했다 — 숙련도에 따라 대응 속도·품질이 갈렸다 |
| **성과·검증** | 소재 교체·입찰가 조정의 착수 시점이 월말 리뷰에서 "리포트를 여는 즉시"로 단축 |
| **경쟁 비교** | 아드리엘의 'AI 인사이트'가 유사하지만 LLM 기반이라 **구독·토큰 비용이 들고 실행이 느리며 결과가 매번 달라질 수 있다**. 에이비딩은 입찰 "실행"만 자동화할 뿐 왜 그래야 하는지 진단은 없다. **우리가 나은 점**: ①결정적 룰 엔진이라 **비용 0·즉시·재현 가능**, 모든 제안에 근거 수치 병기로 검증 가능. ②제안("소재 점검·교체")이 **같은 제품의 소재 편집 기능(④⑤)으로 바로 이어진다** — 진단과 처방이 분리된 경쟁 구도에서 유일하게 연결된 루프 |

## 영역 2 — 크리에이티브: 액션 제안이 가리킨 "소재 작업"을 같은 제품 안에서

### ③ 경쟁사(이미지팩토리) 벤치마크 리서치

**결론: 크리에이티브 3종(④⑤⑥)의 구현 방향을 업계 표준에 맞춰 확정하고, 우리의 차별점(성과→소재 역방향 루프)을 발견했다.**

| 구분 | 내용 |
|---|---|
| **언제** | 2026-11-10 완료 |
| **어디서** | imagefactory.co.kr 공식 사이트·기술 블로그·API 문서 |
| **무엇을** | 요소 편집·배경 변형·규격 리사이즈의 구현 방식과 비즈니스 모델(종량 과금, 무료 운영 기능으로 묶는 해자 구조) 분석 |
| **어떻게** | 공개 기술 문서 분석 — 세이프존 전략 11종 벤치마크, 레이어 편집의 한계(자사 생성 이미지에서만 동작) 등 |
| **왜** | 이미지 기능 3종을 만들기 전에 검증된 방식을 확인해 시행착오 비용을 줄이기 위해 |
| **성과·검증** | "임의 업로드 이미지의 부분 수정 = 요소 인식→클릭 선택→선택 영역만 수정"이 업계 표준임을 확인하고 ④의 설계로 채택 |
| **경쟁 비교** | 리서치 자체가 경쟁 분석 — 핵심 발견은 이미지팩토리의 간판 기능인 레이어 편집이 **자사 워크스페이스에서 생성한 이미지에서만 완전 동작**한다는 한계(블로그에서 자인). 우리는 이 한계 지점(임의 업로드 이미지)을 ④의 타깃으로 삼았다 |

### ④ 요소 분석 기반 이미지 간편 편집

**결론: "왼쪽 위 할인 문구만 바꿔줘"를 말로 설명할 필요 없이, AI가 찾아낸 요소를 클릭 한 번으로 고르면 그 부분만 정확히 수정된다.**

| 구분 | 내용 |
|---|---|
| **언제** | 2026-11-10 완료 |
| **어디서** | 이미지 정제 화면 "요소 선택" 단계 (신설) |
| **무엇을** | 업로드 이미지에서 구성 요소(헤드라인·로고·제품·뱃지·버튼·배경, 최대 12개)를 자동 검출해 이미지 위 박스로 표시 — 클릭으로 수정 대상 특정 |
| **어떻게** | Gemini Vision이 요소와 좌표(bounding box)를 추출 → 선택 요소의 이름·위치를 "이 영역만 수정, 나머지 유지" 지시문으로 자동 변환해 편집 모델에 전달. AI 사용량 로그·월 예산 게이트 연동 |
| **왜** | 기존 자유 프롬프트 방식은 부분 수정 위치를 말로 설명해야 했고 결과가 불안정했다 — 광고 소재의 흔한 수정(문구 교체, 뱃지 숫자 변경)이 디자이너 왕복을 유발 |
| **성과·검증** | 실제 광고형 배너로 요소 12개 검출·선택 흐름 화면 검증, 파싱 견고성 테스트 6건 추가 |
| **경쟁 비교** | 이미지팩토리의 레이어 편집은 **자사에서 생성한 이미지 한정**이고, 임의 업로드 이미지는 마스킹(영역을 직접 칠하기)으로 후퇴한다. 포토샵·캔바도 수정 영역을 사람이 직접 지정해야 한다. **우리가 나은 점**: **임의 업로드 이미지(기존 보유 소재)에서 AI가 요소를 자동 검출**하고 클릭 1번으로 영역이 특정된다 — "이미 갖고 있는 소재를 고치는" 실무 시나리오에서 가장 빠른 경로. 이미지팩토리처럼 자사 생성 이미지로 유도할 필요가 없어 기존 소재 자산이 그대로 활용된다 |

### ⑤ 이미지 배경 자동 제안

**결론: 버튼 한 번으로 피사체는 그대로 두고 배경만 바꾼 시안 4종이 나란히 나온다 — "프롬프트 쓰고 1장 확인"의 반복이 "클릭 1번, 4안 비교"로 줄었다.**

| 구분 | 내용 |
|---|---|
| **언제** | 2026-11-10 완료 |
| **어디서** | 이미지 정제 화면 "배경 시안 제안" 카드 (신설) |
| **무엇을** | 스타일 프리셋 4종(스튜디오 화이트·밝은 그라데이션·자연광 야외·럭셔리 다크) 배경 시안을 그리드로 제시, 개별 다운로드·재생성 지원 |
| **어떻게** | Gemini 이미지 생성을 프리셋별 병렬 호출 — 일부 실패해도 성공분만 표시, 토큰은 합산해 사용량 로그 1줄로 기록, 월 예산 게이트 연동 |
| **왜** | 배경 교체는 수요가 많은 작업인데 1장씩 수동 생성해야 해서 "여러 안을 놓고 고르는" 시안 비교가 불가능했다 |
| **성과·검증** | 병렬·부분 실패·토큰 합산 테스트 4건 + UI 전체 흐름 화면 검증. 경쟁사의 변형(Vary) 개념을 배경에 특화 적용한 첫 사례 — 카피·레이아웃 변형으로 확장 가능 |
| **경쟁 비교** | 이미지팩토리의 변형(Vary) 생성이 가장 가깝지만 **포인트 종량제(이미지 1장 ≈ $1 수준)**다. **우리가 나은 점**: ①AI 원가 그대로(1장 ≈ $0.04, 4안 1클릭 ≈ $0.16) — **원가 구조가 20배 이상 유리**해 "일단 여러 안 뽑아보는" 사용 방식이 가능. ②스타일을 골라 생성 수를 제어할 수 있어 비용이 예측 가능. ③성과 리포트와 같은 화면이라 "ROAS 떨어진 소재 → 바로 배경 시안"으로 이어진다 |

**결론: 소재 1장이 클릭 한 번에 Meta·Google·YouTube·Naver·Kakao 8개 지면 규격의 zip으로 떨어진다 — AI 비용 0원.**

| 구분 | 내용 |
|---|---|

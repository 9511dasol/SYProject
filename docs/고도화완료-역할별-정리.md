| # | 완료한 것 | 무엇이 달라졌나 |
|---|---|---|

| F2 | **에러 메시지 추출 8벌 → 1벌, 다운로드 코드 4벌 → 1벌** | 파일마다 달랐던 `detail`/`message` 우선순위를 고정 — 서버가 준 사유를 잃지 않음 |

| F4 | **키워드 비교 표 점진 렌더** — 300행씩 + "더 보기", 행 키를 안정적 식별자로 | 수천 행 필터·정렬 시 멈춤 해소. 중복 조합에서 **행이 화면에서 사라지던** 키 충돌까지 수정 |

| F6 | **이미지 교체 경합 차단** — 선택 세대(generation) 가드 | 큰 그림 → 작은 그림으로 빠르게 바꿀 때 늦게 도착한 치수가 새 파일 값을 덮어쓰지 못함 |
| F7 | **리포트 브라우저 보관 정비** — 보관 10개 상한 + 오래된 것 자동 정리, 용량 초과 시 안내 | 조용히 실패하고 다음 방문에 리포트가 사라져 있던 경로 제거 |

## 🔧 BACK 개발자 관점

**결론부터: 동시성·데이터 원자성이라는 구조 문제를 먼저 풀고, 쿼리·인덱스·공용화·테스트로 바닥을 다졌습니다.**

| # | 완료한 것 | 무엇이 달라졌나 |
|---|---|---|
| B1 | **async 블로킹 제거 (19개 지점)** — 가짜 async를 동기+스레드풀로, 유지 필요한 곳은 블로킹 구간만 분리 | AI 작업 1건이 서버 전체를 멈추던 구조 해소. **2.40초 → 1.21초 실측** (대조군으로 측정 유효성 입증) |
| B2 | **데이터 쓰기 원자성** — 순서를 "복구 지점 확보 → 삭제 → 저장"으로 역전, 실패 시 자동 복구, 엑셀 교체 경로에도 동일 적용 | 저장 실패 시 한 달치 데이터가 복구 수단 없이 사라지던 경로 제거 |
| B3 | **LLM 한도** — 3사 클라이언트 타임아웃·재시도(텍스트 60초/이미지 180초), Gemini 생성 지점 4곳 → 1곳, `attempts` 의미 차이 보정 | 공급자 무응답 시 무한 대기 제거, 재시도 횟수가 공급자마다 달랐던 불일치 해소 |
| B4 | **쿼리·인덱스** — `created_at` 인덱스 2종(마이그레이션 0007), 월별 필터를 `extract()` → 날짜 범위 조건 6곳, 예산 조회 전체 로드 → SQL 1행 | 쓸수록 느려지던 AI 예산 집계·월별 조회가 인덱스를 탐 |
| B5 | **전역 예외 핸들러 + 오류 기준** — 5xx는 사유를 로그에만, 4xx는 사유 그대로, 관리자 진단 화면은 예외 | 내부 예외 메시지가 사용자 화면에 노출되던 14곳 정리 |
| B6 | **비밀번호 정책 통일** — 검증 함수 1개를 4경로(가입·관리자 생성·변경·재설정)에 적용 | **1자리 비밀번호로 가입되던** 구멍 폐쇄 |
| B7 | **공용 모듈화** — 알파 합성 4곳 → `image_util`, LLM JSON 해석 2곳 → `llm_json`, 사용량 기록 5곳 → `log_ai_usage` | 같은 이미지가 기능마다 다르게 보이던 문제 해소 (요소 분석은 투명 영역이 **검게** 깔리고 있었음). 기록 실패가 사용자 요청을 깨뜨리지 않음 |
| B8 | **발송 경로 정리** — GET 메일 발송 → POST + 관리자 + 예산 게이트, 발송 기록은 전용 세션 | 프리페치로 메일이 나갈 수 있던 경로와 요청 세션 오염 제거 |
| B9 | **운영 정합** — 워커 스레드 수를 DB 커넥션 풀 크기에 정렬(기동 시 자동), 풀 10+20 상향 | 스레드는 남는데 커넥션이 없어 대기하다 실패하던 조합 제거 |
| B10 | **테스트 +211건** — 업로드 입구 48, 작업 상태 저장소 22, 캐시 24, YoY 17, 리사이즈 17, 스토리지 16 등 | "테스트가 없어서 통과"하던 핵심 경로에 안전망. 실효 검증: 운영 코드를 일부러 되돌려 **실제로 실패하는지** 확인 |
| B11 | **죽은 코드 삭제** — 한 번도 등록된 적 없는 태스크 모듈 3파일 | 사실과 다른 docstring 제거 + 같은 이름 스키마 충돌 해소 |
| B12 | **AI 코멘트 캐시** — 프롬프트 지문 기반 재사용(마이그레이션 0008), 재사용은 사용량 집계 제외 | 같은 질문 중복 구매 제거, 월 예산이 실제 사용량과 일치 |
| B13 | **AI 코멘트 YoY** — 당월 vs 전월 vs 전년 동월, 없는 달은 가장 가까운 보유 월로 대체 + 고지 | 계절성 반영. 같은 달을 두 번 쓰지 않는 중복 방지 포함 |

## 🌐 Full-stack 개발자 관점 (front ↔ back 경계)

**결론부터: "계약 없는 수동 동기화"였던 경계에 계약과 일관된 규칙을 깔았습니다.**

| # | 완료한 것 | 경계가 어떻게 달라졌나 |
|---|---|---|
| FS1 | **엑셀 리포트 응답 계약** — 백엔드 Pydantic 스키마 + `response_model` | 파서가 키를 바꾸면 프론트에서 조용히 빈칸 → 이제 **서버에서 걸림**. OpenAPI에 실려 타입 코드젠의 기반 확보. 셀 값 타입은 의도적으로 열어 둠(목적은 구조 드리프트 차단) |
| FS2 | **BFF 스트리밍** — 파일 바디를 버퍼링 없이 패스스루 | 응답 크기 제한으로 "메일로 받기" 우회를 만들던 근본 원인 제거. 압축 응답에서 파일이 잘릴 수 있던 Content-Length 잠복 버그까지 차단 |
| FS3 | **오류 응답 한 쌍 정리** — 백엔드 전역 핸들러 + 프론트 공용 추출을 같은 규칙으로 | 같은 오류가 화면마다 다른 문구로 보이던 문제 해소 |
| FS4 | **취소 체계 관통** — 프론트 AbortSignal ↔ 백엔드 무제한 경로 설계(조회는 30초 상한, AI는 상한 대신 취소) | "브라우저는 끊었는데 서버는 계속 돌아 중복 실행"되던 경로(메일 재발송 이중 발송 등) 제거 |
| FS5 | **상태 플래그 관통** — `cached` 가 백엔드 → BFF → 화면까지 그대로 전달 | 서버의 판단(재사용 여부)을 UI가 정확히 표현 |
| FS6 | **코드젠 장애물 제거** — 이름만 같고 필드가 다른 스키마 충돌 해소, 미등록 API 삭제 | OpenAPI 기반 타입 생성 시 한 이름으로 뭉개질 자리 제거 |

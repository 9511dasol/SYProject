## 3. 이미지팩토리 구현 방식 리서치 — 2026-11-10 완료

**목적** — 크리에이티브 고도화(4~6번)의 구현 방향을 벤치마크 리서치로 확정.

**결과 요약** (상세: [imagefactory-research.md](imagefactory-research.md))
- 요소 편집: 임의 업로드 이미지는 "요소 인식 → 클릭 선택 → 선택 영역만 수정(인페인팅)"이 업계 표준 — 4번 과제의 구현 방향으로 채택
- 배경/변형: 스타일 프리셋 기반 병렬 변형 생성 → 그리드 제시 — 5번 과제 방향
- 리사이즈: 비율 차이에 따른 전략 자동 선택(단순 리사이즈 ↔ AI 아웃페인팅) + 동일 비율 생성 공유로 비용 절감 — 6번 과제 방향
- IR 포인트: 경쟁사는 "소재 제작→집행→성과" 루프가 해자. 우리는 실데이터 리포트·액션 제안(1·2번)이 크리에이티브 도구(4~6번)로 이어지는 역방향 흐름이 차별점.

## 4. 요소 분석 기반 이미지 간편 편집 — 2026-11-10 완료

**배경 / 문제**
- 기존 '이미지 정제'는 자유 텍스트 프롬프트만 받아서, "왼쪽 위의 할인 문구만 바꿔줘" 같은 부분 수정은 사용자가 위치를 말로 설명해야 했고 결과도 불안정했다.
- 벤치마크(이미지팩토리) 리서치 결과, 임의 업로드 이미지의 부분 수정은 "요소 인식 → 클릭 선택 → 선택 영역만 수정"이 업계 표준 방식.

**개선 내용**
- **요소 분석 단계 신설**: Gemini Vision이 업로드 이미지에서 구성 요소(헤드라인·로고·제품·뱃지·버튼·배경 등 최대 12개)를 bounding box와 함께 자동 검출.
- **클릭 선택 UI**: 검출된 요소를 이미지 위에 박스 오버레이로 표시 — 박스나 칩을 클릭해 수정 대상을 특정. 선택하지 않으면 기존 전체 편집 그대로.
- **정밀 편집 지시 자동 조합**: 선택한 요소의 이름·위치(비율 좌표)를 "이 영역만 수정, 나머지는 유지" 지시문으로 자동 변환해 편집 모델에 전달 — 사용자는 "문구를 겨울 세일로 바꿔줘"만 쓰면 된다.
- 요소 분석도 관리자 AI 사용량 로그·월 예산 게이트에 연동 (도구명: 이미지 요소 분석).

**기대 효과**
- 디자인 비전문가도 클릭 한 번으로 수정 지점을 특정 — 부분 수정의 지시 정확도와 재현성 향상.
- 광고 소재의 흔한 수정 요청(문구 교체, 뱃지 숫자 변경, 로고 정리)을 디자이너 왕복 없이 처리.

**검증**: 실제 광고형 배너로 요소 12개 검출·오버레이·선택 흐름을 화면으로 확인. 응답 파싱 견고성 테스트 6건 추가(전체 328건 통과). 구현 중 발견한 함정 — gemini-2.5는 thinking 토큰이 출력 한도를 소모해 JSON이 잘릴 수 있어 탐지 작업은 thinking을 끄고 호출한다.

## 5. 이미지 배경 자동 제안 — 2026-11-10 완료

**배경 / 문제**
- 광고 소재의 배경 교체는 수요가 많은 작업인데, 기존에는 프롬프트를 직접 써서 1장씩 만들어야 했다 — "여러 안을 놓고 고르는" 시안 비교가 불가능했다.

**개선 내용**
- 이미지 정제 화면에 **"배경 시안 제안" 카드** 신설: 버튼 한 번으로 피사체(제품·인물·문구)는 유지한 채 배경만 바꾼 시안 4종을 자동 생성해 그리드로 제시.
- 스타일 프리셋: 스튜디오 화이트 · 밝은 그라데이션 · 자연광 야외 · 럭셔리 다크 (광고 소재 수요 순).
- Gemini 이미지 생성을 **프리셋별 병렬 호출** — 일부 스타일이 실패해도 성공한 시안만 보여주고, 토큰은 합산해 사용량 로그 한 줄로 기록(도구명: 배경 시안 생성). 월 예산 게이트 연동.
- 마음에 드는 시안은 그 자리에서 다운로드, "다시 만들기"로 재생성.

**기대 효과**
- 배경 A/B 시안 제작이 "프롬프트 작성 → 1장 확인"의 반복에서 "클릭 한 번 → 4안 비교"로 단축.
- 벤치마크(이미지팩토리)의 변형(Vary) 개념을 배경에 특화해 적용한 첫 사례 — 추후 카피·레이아웃 변형으로 확장 가능.

**검증**: 병렬 호출·부분 실패·토큰 합산 로직 모킹 테스트 4건(전체 332건 통과), UI 흐름과 오류 안내 경로 화면 확인. 실제 시안 생성 화면 검증은 Gemini 이미지 모델 쿼터 리셋 후 1회 실행으로 확인 예정.

## 6. 이미지 리사이징 고도화 (매체 규격 일괄 변환) — 2026-11-10 완료

**배경 / 문제**
- 기존 리사이저는 지정 크기로 "늘려서" 맞추는 방식이라 비율이 다른 지면에선 이미지가 찌그러졌고, 매체마다 규격이 달라 소재 1장을 지면별로 일일이 변환해야 했다.

**개선 내용**
- **매체 규격 프리셋 8종** 내장: Meta 피드 1:1 / 4:5 / 스토리·릴스 9:16, Google 디스플레이 1.91:1 / 1:1, YouTube 썸네일 16:9, Naver 모바일 DA, Kakao 비즈보드.
- **비율 유지 중앙 크롭(cover) 변환** — 찌그러짐 없이 각 지면을 가득 채운다.
- **일괄 ZIP 다운로드**: 원하는 규격을 체크(또는 전체 선택)하면 소재 1장이 선택 규격 전부로 변환되어 zip 한 파일로 떨어진다. 파일명에 매체·크기가 들어가 입고 시 헷갈리지 않는다.
- 순수 Pillow 경로라 AI 비용 0 — 무제한 사용 가능.

**기대 효과**
- "소재 1장 → 전 매체 입고본" 제작이 클릭 한 번으로 단축 (기존: 지면 수만큼 수동 변환).
- 벤치마크(이미지팩토리)의 1,400개 지면 자동 변환을 국내 핵심 지면 8종으로 경량 구현한 1단계. 비율 차이가 큰 띠배너의 AI 아웃페인팅 채움, 스토리 세이프존 대응은 다음 확장 지점.

**검증**: cover 크롭 기하·zip 구성 테스트 5건(전체 337건 통과). 실화면 E2E — 업로드 → 전체 선택 → zip 다운로드 → 압축 해제 후 8개 파일 모두 규격 일치 확인.

## 1. YoY/MoM 기간 비교 리포트 — 2026-11-10 완료

**배경 / 문제**
- 월간 리뷰 화면은 선택한 달의 실적만 보여줘서, "지난달보다 좋아졌는가", "작년 이맘때와 비교하면 어떤가"를 보려면 달을 오가며 수치를 수기로 비교해야 했다.
- 광고는 계절성이 강해(예: 10월 성수기) 전월 비교만으로는 성과 판단이 왜곡된다 — 전년동월(YoY) 비교가 필수.

**개선 내용**
- 리포트 API가 당월 실적과 함께 **전월(MoM)·전년동월(YoY) 합계를 같이 반환**하도록 확장. 파생지표(CTR·CPC·ROAS)는 당월 리포트와 동일한 공식으로 계산해 증감률 왜곡을 방지.
- 대시보드 요약 탭에 두 가지 뷰 추가:
  - **KPI 카드 증감 칩**: 지표 10종 카드마다 `전월 +16.3% · 전년 -24.2%` 식 증감 표시. 양(量) 지표는 %, CTR·ROAS 같은 비율 지표는 %p로 표기. 색상은 "개선 여부" 기준(CPC는 하락이 초록, 광고비는 중립).
  - **기간 비교 표**: 전년동월 | 전월 | 당월 3개 기간을 지표별로 나란히 놓고 전년比·전월比를 함께 표시 (예: 25년 10월 vs 26년 9월 vs 26년 10월).
- 비교 달 데이터가 없으면 비교 블록을 숨겨 "-100%" 같은 거짓 증감이 나오지 않게 처리.

**기대 효과**
- 월간 리뷰에서 성과의 "방향"이 한눈에 보임 — 달을 오가며 수기로 비교하던 작업 제거.
- 계절성을 걷어낸 전년동월 비교로 성과 해석 정확도 향상. DB에 쌓인 과거 기간 데이터(2025-01~)의 활용 가치가 커짐.
- 백엔드 회귀 테스트 3건 추가, 전체 테스트 322건 통과로 안정성 확보.

## 2. CTR/ROAS 지표 기반 액션 제안 — 2026-11-10 완료

**배경 / 문제**
- 대시보드가 CTR(클릭률)·ROAS(비용 대비 매출) 수치를 보여주지만, 그래서 **무엇을 해야 하는지**는 담당자가 경험으로 판단해야 했다. 수치를 읽는 사람의 숙련도에 따라 대응 속도와 품질이 달라졌다.

**개선 내용**
- 요약 탭에 **"액션 제안" 섹션** 신설. 지표 상태를 읽어 점검이 필요한 신호와 권장 액션을 카드로 제시:
  - **ROAS 100% 미만** (광고비 > 매출) → 키워드 입찰가 하향 검토, 저효율 키워드 제외, 예산 재배분
  - **ROAS 전월 대비 급락** → 키워드 입찰가 확인, 매출 상위 키워드 집중
  - **CTR 하락** (소재 피로도 의심) → 소재 점검·교체, 카피/이미지 A·B 테스트
  - **CPC 급등** (입찰 경쟁 심화) → 입찰가 확인, 품질지수 점검
  - **전환율 하락** → 랜딩페이지·전환 경로 점검
  - **매체별 진단**: 특정 매체만 ROAS 100% 미만이거나 CTR이 계정 평균의 절반 이하이면 해당 매체를 지목해 제안
  - **긍정 신호**: CTR·ROAS 동반 개선 시 "잘 되는 소재·키워드 예산 확대" 제안
- 모든 제안에 **근거 수치를 함께 표기** (예: "구글 ROAS 83.3% (계정 전체 159.7%)") — 담당자가 제안의 타당성을 바로 검증 가능.
- AI 호출 없는 **결정적 룰 엔진**이라 토큰 비용 0, 리포트 열 때마다 즉시 계산. 임계값은 상수로 모아 운영하며 조정 가능. (1번에서 만든 전월/전년 비교 데이터를 재사용)

**기대 효과**
- 대시보드가 "수치 조회 도구"에서 **"다음 행동을 알려주는 도구"로 전환** — 주니어 담당자도 데이터 기반 대응 가능.
- 소재 교체·입찰가 조정 같은 핵심 운영 액션의 착수 시점이 빨라짐 (월말 리뷰 때가 아니라 리포트를 여는 즉시).

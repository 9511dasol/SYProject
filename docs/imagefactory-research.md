# 이미지팩토리(imagefactory.co.kr) 리서치 — 2026-11-10

> 고도화 4~6번(요소 편집·배경 제안·리사이징)의 선행 리서치.
> 출처: 공식 사이트, llms-full.txt, 개발자 API 문서, 기술 블로그, 보도자료.

## 1. 서비스 개요

엠제이스튜디오가 만든 **AI 광고 소재 자동화 플랫폼**. "URL 하나로 기획→소재 제작→집행→성과 관리"를 표방하는 AI 광고대행사 포지션으로 확장 중.

- 제공 형태: 웹 워크스페이스 + **Figma/Photoshop 플러그인 + REST API + MCP 서버** (멀티 서피스 전략)
- 핵심 기능 축: ① AI 배너 생성 ② 배너 리사이즈(1,400+ 지면) ③ 요소 편집 ④ 변형(Vary) 생성 ⑤ 다중 채널 게재·성과 관리
- 과금: 포인트 종량제(100pt ≈ 배너 1장 ≈ $1) + 구독($20/50/95월). 광고 운영 기능은 무료, 소재 제작만 과금
- SEO 전략: 매체별 광고 사이즈 가이드 페이지를 지면 단위로 1,400+개 생성해 유입 퍼널로 활용

## 2. 기능별 구현 방식 (기술 관점)

### 2-1. 요소 편집 — "레이어 기반" 방식 (→ 우리 4번 과제)

공식 블로그가 부분 수정 방법 5종을 비교하며 자사 방식을 설명:

| 방식 | UI | 처리 | 한계 |
|------|----|------|------|
| 마스킹/인페인팅 | 영역 마스크 + 텍스트 지시 | 마스크 내부만 재생성 | 경계 블렌딩 어색할 수 있음 |
| 앵커 기반 자연어 | "오른쪽 상단으로" 프롬프트 | 전체 재생성 | 모델 이해도에 따라 편차 |
| 픽셀/퍼센트 좌표 | "x=80, y=60으로" | 전체 재생성 | 모델이 좌표를 잘 못 따름 |
| **이미지팩토리 레이어 방식** | **클릭으로 요소 자동 선택 → 드래그 이동·크기 조절** | **요소를 재생성 없이 그대로 이동, 빈 자리만 배경에 맞춰 채움 (원본 화질 유지)** | **자사 워크스페이스에서 생성한 이미지에서만 동작. 위치 이동만 지원, 내용 수정은 마스킹 필요** |

핵심 통찰: **"원본 PSD/레이어 없이 완성 이미지에서 요소를 인식해 수정"**이 세일즈 포인트지만, 실제로는 *자기들이 생성한 이미지*(= 레이어 정보를 이미 갖고 있는 이미지)에서만 완전한 레이어 편집이 된다. **임의의 업로드 이미지에 대한 요소 편집은 마스킹+인페인팅으로 처리**하는 것이 업계 표준이고, 이미지팩토리도 이 한계를 블로그에서 인정한다.

### 2-2. 변형(Vary) / 배경 (→ 우리 5번 과제)

- 배너 1장에서 **카피·레이아웃·컬러 트리트먼트가 다른 변형 다수를 생성** ("on-brand variations") — A/B 테스트용
- 독립된 "배경 교체" 단일 기능은 전면에 내세우지 않고, 변형 생성과 생성 모드(제품사진→배너) 안에 녹여놓음
- 성과 관리와 연결: "반응 검증된 소재의 자동 변형 제안" — 성과 데이터가 변형 생성의 트리거

### 2-3. 리사이즈 — 전략 자동 선택 + 세이프존 2단계 파이프라인 (→ 우리 6번 과제)

가장 기술 문서화가 잘 된 영역. 종횡비 변화 정도에 따라 **전략을 자동 선택**:

| 전략 | 적용 조건 | 동작 |
|------|----------|------|
| `DYNAMIC_SCALE` | 중간 비율 변화 (8:1 ~ 1:8) | 레이아웃 재구성 중심 |
| `EXTENSION` | 극단적 비율 변화 (띠배너 등) | 아웃페인팅으로 캔버스 확장 |
| `SAFE_ZONE_OUTPAINT` | 세이프존 있는 지면 (스토리/릴스) | 아래 2단계 파이프라인 |

**세이프존 2단계 파이프라인** (전략 11종 벤치마크 후 채택):
1. **구조화 단계**: 핵심 요소(CTA·로고·가격)를 세이프존 안에 *기하학적으로* 고정 배치
2. **생성 단계**: 세이프존 바깥 영역만 AI가 자연스럽게 채움

→ 프롬프트로 "세이프존 안에 배치해줘"라고 지시하는 방식은 품질 점수는 높아도(96.7) 준수율이 70%에 그침. 기하학적 고정은 품질 80.8이지만 **준수율 100% 보장**. "품질 점수와 준수율을 분리해서 평가하라 — 합산 점수는 위반을 가린다"는 QC 방법론 공개.

**비용 최적화**: 같은 종횡비의 출력들은 **AI 생성 1회를 공유하고 정확히 다운스케일** — 1,400 지면을 지원해도 AI 호출은 비율 그룹 수만큼만.

### 2-4. API 구조 (참고)

- `POST /api/external/v1/images/generate` (mode: 프롬프트/카드/레퍼런스, count 1~5)
- `POST /api/external/v1/images/resize` (원본 + 출력 크기 + 자유 지시문 + 세이프존)
- `GET /api/external/v1/tasks/{taskId}` — **비동기 + 폴링** 구조
- `Idempotency-Key` 헤더, 선차감·실패분 환불 과금, OpenAPI 3.1 공개

## 3. 우리 프로젝트 적용 방안

현재 보유 자산: `image_ai_edit_service.py`(Gemini 이미지 생성 — 원본+프롬프트→수정본), `image_resize_service.py`(Pillow 단순 리사이즈+AI 업스케일), 이미지 정제/리사이저 화면, 비동기 task 인프라(`background_tasks` + 폴링).

### 4번: 요소 분석 기반 간편 편집
- 임의 업로드 이미지가 대상이므로 **"요소 인식 → 클릭 선택 → 선택 영역만 수정"** 플로우가 현실적 (이미지팩토리도 임의 이미지는 이 방식)
- 구현: ① Gemini vision으로 이미지 내 요소(텍스트·로고·제품·배경 등)와 bounding box를 JSON으로 추출 → ② 프런트에서 이미지 위에 박스 오버레이, 클릭으로 선택 → ③ 선택 요소 + 수정 지시를 조합한 프롬프트로 기존 `generate_image()` 호출 ("이 영역의 ~만 바꾸고 나머지는 유지")
- 기존 자유 프롬프트 방식보다 **지시 정확도가 오르고, 비전문가도 클릭만으로 수정 지점을 특정** 가능

### 5번: 배경 자동 제안
- "여러 배경을 저절로 보여주기" = 이미지팩토리의 Vary 개념을 배경에 특화
- 구현: 배경 스타일 프리셋 N종(스튜디오·야외·단색·계절감 등)을 템플릿 프롬프트로 정의 → 피사체 유지 지시와 함께 병렬 생성 → 그리드로 제시, 선택 시 원본 교체
- 기존 Gemini 파이프라인 재사용으로 백엔드 추가 작업 적음. 포인트: **피사체 보존 프롬프트**("제품/인물은 그대로, 배경만")와 생성 수 제한(AI 예산 게이트 연동)

### 6번: 리사이징 고도화
- 현재는 단순 비율 리사이즈 → **매체 규격 프리셋 + 비율 차이에 따른 전략 자동 선택**으로 격상
  - 비율 차이 작음 → Pillow 리사이즈(+패딩) — AI 비용 0
  - 비율 차이 큼 → Gemini 아웃페인팅(캔버스 확장) 
- 규격 프리셋: Meta 피드 1:1/4:5·스토리 9:16, 네이버 모바일 DA 1250×560, 카카오 비즈보드 1029×258 등 국내 주요 지면부터
- 이미지팩토리의 교훈 적용: **같은 비율 출력은 생성 1회 공유 후 다운스케일**로 토큰 절약, 세이프존은 2차 고도화로

## 4. IR 관점 참고 포인트

- 이미지팩토리는 소재 제작(과금)과 광고 운영(무료)을 묶어 **"소재→집행→성과→변형" 루프**를 해자로 만들고 있음 — 우리도 "리포트 분석(1·2번) ↔ 크리에이티브(4~6번)"를 한 플랫폼에 묶는 구조가 같은 방향
- 차별점으로 쓸 수 있는 것: 우리는 **사내 실데이터 기반 리포트와 액션 제안이 먼저 있고**, 그 액션("소재 점검·교체")이 크리에이티브 도구로 바로 이어지는 흐름 — "액션 제안에서 '소재 교체' 클릭 → 이미지 정제/배경 제안으로 연결" 같은 연계가 스토리가 됨

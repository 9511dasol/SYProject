# 1. 총괄 — 한 문단 요약

**2026년 11월 10일부터 23일까지 13일간, 제품을 "수치 조회 도구"에서 "다음 행동을 알려주고, 그 행동(소재 제작·순위 감시)까지 한 곳에서 처리하는 도구"로 격상시켰습니다.** 기능 고도화 13건(리포트 분석 4 · 크리에이티브 4 · 플랫폼 기반 5), 신규 기능 1건(키워드 순위 모니터링 — **로드맵 M1~M6 전부 완성, 실제 광고 계정에서 자동 수집까지 검증**), 전 페이지 전수 분석에 따른 개선 5묶음, 사용자 경험 전수 개선 5묶음(11-22), **타입 코드젠 도입과 임시방편 전수 제거(11-22~23)** 를 완료했고, 그 과정에서 자동 테스트를 322건에서 **693건**으로 늘려 모든 변경을 회귀 없이 검증했습니다.

**마지막 묶음의 의미**: 11월 22일, 기능이 아니라 **배치**를 고쳤습니다. 액션 제안과 AI 코멘트는 11월 10일에 이미 만들어 놓고도 화면 맨 아래 접힌 자리에 두어, 담당자가 "무엇을 해야 하는지"를 스크롤 끝에서야 만나고 있었습니다. 만든 가치가 전달되지 않던 구간을 닫은 작업입니다.

**IR 핵심 스토리 한 줄**: 경쟁사는 "소재 제작 → 집행 → 성과"로 흐르지만, 저희는 **"실데이터 성과 분석 → 액션 제안 → 소재 제작 → 순위 감시"의 역방향 루프**입니다. 리포트가 "소재를 점검하라"고 말하면 같은 화면에서 바로 소재를 고치고, 고친 소재의 키워드 순위가 떨어지면 아침에 메일로 알려줍니다.

## 3-2. 우위에 있는 부분 (구체적 근거와 함께)

1. **역방향 루프 — 유일한 연결 구조입니다.** 진단(액션 제안)과 처방(소재 편집·배경 시안)이 분리된 경쟁 구도에서, "CTR 하락 → 소재 점검 제안 → 같은 화면에서 소재 수정"이 이어지는 제품은 저희뿐입니다.
2. **엑셀 호환성 — 당일 시작이 가능합니다.** 실무에서 쓰던 엑셀 리포트 양식('전월'·'전년동월' 행)과 지표 정의가 1:1로 일치하므로, API 연동·셋업 없이 쓰던 파일을 올리는 것만으로 과거 35개월치 비교가 즉시 가동됩니다. 실제로 양식이 전혀 다른 대행사 주간 리포트(25MB `.xlsb`)를 업로드 기능으로 적재해 19개월 → 35개월로 늘린 사례가 있습니다(2026-11-24). 대시보드 숫자와 보고서 숫자가 어긋나는 범용 툴의 고질 문제가 없습니다.
3. **원가 구조 — 배경 시안 기준 20배 이상 유리합니다.** 이미지팩토리는 이미지 1장 ≈ $1의 포인트 종량제이지만, 저희는 AI 원가 그대로(1장 ≈ $0.04, 4안 1클릭 ≈ $0.16)입니다. 액션 제안(룰 엔진)·규격 변환(이미지 처리)·순위 적재는 아예 0원이라 "일단 여러 안 뽑아보고, 매일 쓰는" 사용 방식이 성립합니다.
4. **임의 업로드 이미지의 요소 편집 — 경쟁사의 자인된 한계 지점을 타깃했습니다.** 이미지팩토리의 간판 기능인 레이어 편집은 자사 워크스페이스에서 생성한 이미지에서만 완전 동작하고(공식 블로그에서 인정), 임의 업로드 이미지는 사용자가 영역을 직접 칠하는 마스킹으로 후퇴합니다. 저희는 **이미 갖고 있는 소재**에서 AI가 요소 12개를 자동 검출하고 클릭 1번으로 영역을 특정합니다.
5. **결정적 룰 엔진 — 비용 0 · 즉시 · 재현 가능합니다.** 아드리엘의 'AI 인사이트'는 LLM 기반이라 구독·토큰 비용이 들고 결과가 매번 달라질 수 있습니다. 저희 액션 제안은 모든 제안에 근거 수치를 병기(예: "구글 ROAS 83.3% (계정 전체 159.7%)")해 담당자가 타당성을 바로 검증할 수 있습니다.
6. **약관을 지키는 순위 모니터링 — 리포트와 결합됩니다.** 경쟁 솔루션의 "분 단위 실시간 순위"는 검색 결과 화면 직접 수집이라 매체 약관 위반 소지가 있습니다. 저희는 공식 데이터(키워드 보고서 → 추후 공식 API) 기반으로 "매일 아침 순위를 대신 확인하고 이상이 있으면 알려주는" 포지션을 택했고, 이는 리포트 자동화라는 제품 중심과 맞닿아 있습니다.
7. **데이터 소유권 — 성과 데이터가 외부 SaaS에 있지 않습니다.** 자체 구축이라 보안을 직접 통제하고, 되돌리기(undo)·스냅샷 같은 자사 워크플로우 맞춤 보호 장치를 넣을 수 있습니다. 이번 라운드에서 그 자체 구축의 약점이던 안정성을 SaaS 수준으로 끌어올렸습니다.

# 4. 무엇을 했나 — 3단계 타임라인 (6하원칙)

## 4-1. 기능 고도화 — "숫자를 보여주는 도구"에서 "행동을 알려주는 도구"로

**결론: 리포트가 방향(YoY/MoM)과 처방(액션 제안)을 말하고, 그 처방을 실행할 크리에이티브 도구 3종이 같은 제품 안에 생겼습니다.**

| 항목 | 언제 | 어디서 | 무엇을 | 어떻게 | 왜 |
|---|---|---|---|---|---|

### 어떻게 검증했나

로컬 SQLite 스택을 띄우고 **ROAS 72%·CTR 전월 대비 -3.4%p처럼 경고가 실제로 발생하는 데이터**를 시드해 브라우저로 확인했습니다. 화면이 그려지는지가 아니라 의도한 신호가 뜨는지를 봤습니다.

| 확인 항목 | 실제 관측 결과 |
|---|---|
| 리포트 배치 | `점검 필요 2건` 배너 → KPI(ROAS 카드에 "광고비가 매출보다 큽니다") → 액션 제안 ② → **코멘트 전문 펼침** 순으로 렌더 |
| 순위 목록 | `목표를 벗어난 키워드 3건 · 전체 6건` 요약 + `하락 2/주의 1/노출없음 1` 칩, 등록순으로 넣은 데이터가 하락→주의→노출없음→정상 순으로 재정렬 |
| 확인 모달 | 권한 변경 시 모달 표시 → **취소하면 드롭다운이 원래 값으로 복귀** → 확인 시 반영 + 성공 토스트 |
| 기능 플래그 | 끄기는 확인 모달, 켜기는 확인 없이 즉시 — 의도한 비대칭 동작 |
| 폼 검증 | 음수 입력 시 "노출수는 0 이상이어야 합니다."가 **해당 입력칸 바로 아래** 표시, 저장 차단 |
| 알림 센터 | 뱃지 `1`, 패널에 "리포트 발송 실패 2건 / 최근 7일" |

타입 검사·프로덕션 빌드 통과, 그룹별 커밋 5건이 **각각 독립적으로 타입 검사를 통과**하는 것까지 확인했습니다.

### 곁들여 잡은 것

검증 도중 발견한 별개 결함 3건도 함께 고쳤습니다. ① 지난 달 리포트에서 '행 추가'의 기본 날짜가 오늘이라 입력칸 범위에 걸려 브라우저가 이유 없이 저장을 막던 것 ② `.xls` 파일이 클라이언트 검증을 통과한 뒤 서버에서 정체불명의 파싱 오류로 떨어지던 것 ③ 미리보기를 띄운 뒤 기간을 바꾸면 미리본 것과 다른 기간이 발송될 수 있던 것.

### 적용하지 않은 것 (근거와 함께)

전수 분석에서 나온 **상 10건 중 2건은 이번에 적용하지 않았습니다.** 둘 다 이미지 리사이저 건으로, 변환 결과를 미리보기 없이 자동 다운로드하는 점과 AI 업스케일에 취소 수단이 없는 점입니다. 이미지 정제 화면에는 두 기능이 모두 있어 **같은 제품 안에서 경험이 갈리는 상태**이므로, 리사이저 결과 프리뷰 도입과 묶어 다음 묶음으로 넘겼습니다(8장 백로그). 중 등급에서는 이미지 정제의 전후 비교 뷰, 헤딩 문구 생성 완료 시 결과 안내와 전체 복사가 남아 있습니다.

# 6. 신규 기능 로드맵 — 키워드 순위 모니터링 (M1~M6 전부 완성)

# 7. IR에서 솔직하게 밝힐 전제

과장으로 읽히지 않도록 아래를 함께 말씀드리는 편이 좋습니다.

1. **AI 호출 절감 효과는 사용 패턴에 비례합니다.** 매달 새 데이터가 들어오는 정상 흐름에서는 원래대로 생성됩니다 — 절감은 "같은 달을 몇 번 다시 보느냐"에 달려 있어, 수치 주장 전 운영 로그의 재호출 비율 확인을 권합니다.
2. **동시 처리 수치(2.40→1.21초)는 동시 요청 2건 기준**입니다. 더 큰 부하의 처리량은 별도 측정이 필요합니다.
3. **순위 데이터는 일 단위(전일 확정치)입니다.** "분 단위 실시간"은 약관 위반 소지가 있어 의도적으로 선택하지 않았습니다.
4. **Gemini 이미지 생성은 유료 등급 API 키가 전제**입니다 (무료 등급 허용량 0건).
5. **플랫폼 기반 작업(P0~P3)은 기능 추가가 아니라 기반 정비**입니다 — 사용자 눈에 보이는 변화는 취소 버튼·미리보기·재사용 안내 정도이지만, 동시 사용과 데이터 신뢰성이라는 전제를 만든 작업입니다.

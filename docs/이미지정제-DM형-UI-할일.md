## 2026-11-28 — 현황 점검 + 할 일 최초 등록

### 1. 점검 결과 (두괄식)

**부분적으로만 DM형입니다.** "지난 작업을 열어 보는 화면"은 DM처럼 생겼지만, **실제로 작업하는 화면은 DM이 아니라 캔버스 + 지시 패널 2열 작업대**입니다.

| 인스타 DM 요소 | 현재 상태 | 근거 |
|---|---|---|
| 왼쪽 대화 목록 | △ 있음 — 단, **앱 사이드바를 접었을 때만** 보임 | `HistoryRail.tsx` (`sidebarCollapsed &&` 조건, `ImageFilterClient.tsx:951`) |
| 목록 항목에 썸네일(프로필 사진 자리) | ✗ 없음 — 아이콘 + 파일명 + 첫 지시 한 줄 | `HistoryRail.tsx:80-92` |
| 대화 헤더 (상대 이름 · 상태) | △ 파일명 · 경과 시간 · 지시 건수 | `ThreadView.tsx:50-68` |
| 내 메시지 = 오른쪽 말풍선 | ○ 있음 | `ThreadView.tsx:86-110` |
| 상대(AI) 답 = **왼쪽** 말풍선 | ✗ 결과 시안도 **오른쪽 정렬** — 주고받는 대화로 안 읽힘 | `ThreadView.tsx:114` (`justify-end`) |
| 하단 메시지 입력창 | ✗ 스레드 하단은 **이미지 업로드 버튼뿐**, 글을 쓸 수 없음 | `ThreadView.tsx:157-188` |
| 보내면 말풍선이 바로 쌓임 | ✗ 스레드는 **읽기 전용 기록 열람**. 이미지를 올리는 순간 스레드가 닫히고 작업대로 전환 | `ImageFilterClient.tsx:396` (`setThreadGroup(null)`) |
| 작업 중에도 대화 형태 유지 | ✗ 작업 화면은 `CanvasStage` + `InstructionPanel` (지시 카드 · 체크박스 · 전송 버튼) | `ImageFilterClient.tsx:962-1028` |
| 생성 중 "입력 중…" 표시 | ✗ 캔버스 위 상태 문구로만 표시 | `statusText` |
| 대화 단위 | △ **파일명**으로 묶음 — 같은 이름의 다른 이미지가 한 대화로 합쳐짐 | `HistoryRail.tsx:64` |

정리하면 지금 구조는 **"DM처럼 생긴 기록 뷰어 + 별도 작업대"** 입니다.

### 2. 먼저 정해야 할 것 (결정 필요)

기존 재설계 기획(2026-11-25, §6)에서 **"채팅 피드 → 캔버스 + 버전 레일 교체"** 를 확정했습니다. 당시 채팅형을 걷어낸 이유는 ① 결과 이미지가 320px 썸네일로만 보임 ② 써 둔 지시가 전부 함께 전송되는 사고였습니다. DM형으로 가려면 이 두 문제가 되살아나지 않아야 합니다.

- [x] **D1. 전환 범위 결정** — **안 A 확정 (2026-11-28)**. 11/25 기획의 "캔버스 + 버전 레일" 결정은 유지하고, 그 왼쪽에 대화 목록 · 스레드를 붙입니다.
  - **안 A (확정) — DM 껍데기 + 캔버스 유지**: 왼쪽 대화 목록 · 가운데 대화 스레드(작업 중에도 유지) · 오른쪽 캔버스 3열. 말풍선의 시안을 누르면 캔버스에 크게 뜸. 요소 지정 · 확대 · 버전 비교를 잃지 않음.
  - 안 B — 완전 DM: 캔버스를 없애고 스레드 하나로. 요소 박스 지정은 이미지 말풍선을 눌러 여는 모달로 이전. 단순하지만 큰 이미지 확인 동선이 한 번 더 듦.
- [ ] **D2. 전송 방식** — DM은 "엔터 = 즉시 전송"인데, 전송 1회가 AI 이미지 생성 N회(과금)입니다. 즉시 전송으로 갈지, 지금처럼 지시를 모아 `전송` 버튼으로 보낼지.
- [ ] **D3. 대화 단위** — 파일명 묶음 유지 vs 서버에 대화(thread) id 도입. 후자는 백엔드 · 마이그레이션 변경이 필요합니다.

### 3. 할 일 (안 A 기준, 위에서부터 순서대로)

**1단계 — 프런트만으로 되는 것 (백엔드 변경 0건)**

- [x] **T1. 대화 목록 상시 노출** (11/28 — 서랍은 미구현, 아래 진행 기록 참고) — `HistoryRail` 을 사이드바 접힘 여부와 무관하게 표시. 폭이 모자라면(<1280px) 목록을 접이식 서랍으로.
- [x] **T2. 목록 항목을 DM처럼** — 원형 썸네일(가장 최근 시안, `editHistoryImageUrl` 재사용) + 파일명 + 마지막 지시 한 줄 + 경과 시간. 보관 만료된 건 기본 아이콘.
- [x] **T3. AI 답을 왼쪽으로** — `ThreadView` 의 결과 시안 묶음을 `justify-start` + 받은 말풍선 모양(`rounded-bl-md`)으로. 만료 안내도 같은 쪽.
- [x] **T4. 스레드를 작업 중에도 유지** — 첨부 시 `setThreadGroup(null)` 로 닫지 않고, 현재 세션의 버전(`useImageVersions`)을 말풍선으로 이어 붙임. 전송한 지시 = 오른쪽 말풍선, 돌아온 시안 = 왼쪽 말풍선.
- [ ] **T5. 하단 입력창을 DM 컴포저로** — `[이미지 첨부] [입력칸] [전송]` 한 줄. `InstructionPanel` 푸터의 입력칸 · 전송 버튼을 이쪽으로 이동. D2 결정에 따라 엔터 동작 확정(한글 조합 중 엔터 가드 `isComposing` 유지).
- [ ] **T6. 보내기 전 지시 = "보낼 예정" 칩** — 입력창 바로 위에 대기 중인 지시를 칩으로 나열(체크 해제 · 수정 · 삭제 가능). 기존 `InstructionCard` 의 선택 전송 안전장치를 그대로 살림.
- [ ] **T7. 생성 중 표시** (11/28 — "입력 중" 말풍선만 완료, 중지 버튼 이동은 T5 와 함께) — 왼쪽에 "입력 중…" 점 세 개 말풍선 + `작업 중지` 버튼. 지금의 `statusText` 문구는 그 말풍선 안으로.
- [ ] **T8. 시안 말풍선 동작** — 누르면 캔버스에 표시(= 버전 선택), 길게 누르기/호버 메뉴로 `이어서 작업` · `저장` · `확대`.
- [ ] **T9. 요소 찾기 · 배경 시안 · 출력 설정 자리 이동** — 오른쪽 패널의 접이식 섹션을 컴포저의 `+` 메뉴(또는 대화 헤더의 ⓘ 정보 패널)로. DM의 "대화 상세"에 해당.
- [ ] **T10. 모바일** — 목록 → 대화 2단 화면 전환(뒤로가기 화살표), 캔버스는 시안 탭 시 전체화면.

**2단계 — D3 에서 대화 id 를 도입하기로 한 경우**

- [ ] **T11.** 편집 기록에 대화 id 컬럼 추가(Alembic) · 기록 조회 응답에 포함 · 프런트 `groupHistory` 를 파일명 대신 대화 id 로.
- [ ] **T12.** 대화 삭제(목록에서 스와이프/메뉴) — 지금은 기록 한 건 단위 삭제만 있음.

### 5. 완료 확인 기준

- 이미지를 올리고 지시를 보내면 **화면 전환 없이** 같은 스레드에 내 말풍선(오른쪽) → 시안 말풍선(왼쪽)이 쌓인다.
- 사이드바를 펼친 상태에서도 대화 목록이 보이고, 목록만 보고 어떤 이미지 작업인지 구분된다.
- 체크를 끈 지시는 전송되지 않는다(기존 안전장치 회귀 없음).
- 시안을 큰 화면으로 확인하는 데 클릭 1회 이내.

## 2026-11-28 — 1단계 T1~T4 구현 (브랜치 `ModifingScreen`)

**한 일**

- **T1** `HistoryRail` 을 늘 렌더합니다. 사이드바가 접혀 있으면 1024px 부터, 펼쳐져 있으면 1400px 부터 섭니다(그보다 좁으면 캔버스가 400px 아래로 줄어듦). 첨부 전 화면 가운데의 지난 작업 블록은 레일이 서는 폭에서만 숨깁니다. 기록 조회는 화면 진입 시 바로 나갑니다.
- **T2** 목록 항목 = 원형 썸네일(가장 최근 보관 시안 첫 장, 만료 시 아이콘) + 파일명 + 경과 시간 + 마지막 지시 한 줄.
- **T3** `ThreadView` 의 결과 시안 · 만료 안내를 왼쪽 "받은 말풍선"으로.
- **T4** 신규 `SessionThread` — 작업 화면 대화 열 맨 위에 이번 작업을 말풍선으로 표시합니다. 올린 이미지 · 보낸 지시는 오른쪽, 돌아온 시안은 왼쪽. 시안을 누르면 캔버스가 그 버전으로 바뀝니다(T8 의 일부). 지난 대화에서 이미지를 올려 시작하면 그 대화가 위쪽에 읽기 전용으로 이어집니다. 생성 중에는 왼쪽에 "입력 중" 말풍선이 뜹니다(T7 의 일부).
- 대화 열(`InstructionPanel`)을 **캔버스 왼쪽**으로 옮겼습니다 — 대화 목록 · 대화 · 캔버스 순서. 모바일 세로 쌓임 순서는 그대로(캔버스 먼저).
- `ImageVersion.batch` 추가 — 요청 1회의 시안 N장을 답 하나로 묶는 기준.

**확인 상태**

- ESLint 통과. `tsc` 는 `.next/types/validator.ts` 의 기존 오류 1건(생성 파일, 이번 변경과 무관)만 남습니다.
- **브라우저 확인 (1440×900, 사이드바 펼침, AI 응답 · 기록 조회는 페이지 안에서 가짜 응답으로 대체)**: 3열 배치(목록 240 · 대화 440 · 캔버스 504px, 페이지 스크롤 없음), 첨부 → 올린 이미지 말풍선, 전송 중 "입력 중" 말풍선, 응답 후 지시(오른쪽) · 시안 3장(왼쪽), 시안 클릭 → 캔버스 · 버전 레일 동기화, 지난 대화 화면의 왼쪽 말풍선, 지난 대화에서 첨부 시 대화가 위에 이어지는 것까지 확인했습니다.
- **실제 Gemini 호출과 실제 보관 이미지 썸네일은 확인하지 않았습니다** — 로그인한 계정에 편집 기록이 없었고, 실호출은 과금이라 돌리지 않았습니다.
